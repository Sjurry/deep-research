Options paper · for the leadership team

Three ways to run quarterly planning

Recommendation

Move to the hybrid model: written proposals first, then one half-day session to decide.

It keeps the live debate people value while cutting total time by about a third. Everyone reads the same proposals before the session, so it's also the only option that gives quieter teams a fair hearing.

Where the time goes

What would change our mind

  • If fewer than half the teams submit a proposal on time in the first cycle, the written round isn't working yet.
  • If the half-day runs over into a second day, we've moved the debate rather than shortened it.
  • If quieter teams' priorities still don't make the final list, fairness hasn't improved and we should look again.
